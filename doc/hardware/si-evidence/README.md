# Field-model run reports

These JSON files are generated by `hw/si/openems_usb_io.py` and
`hw/si/openems_gpu_d0.py` from provenance-checked IO and GPU pipeline boards.
Each report records its exact board hash and, for FDTD runs, the generated
field XML and run-log hashes. The USB report also records the netlist hash and
raw port-trace hashes. The large field and port files remain under ignored
`build/hw/si/`; the commands and interpretation are in
[`../si-models.md`](../si-models.md).

`gpu-d0-legacy-reprocessed.json` and `gpu-d0-pml-short.json` are deliberately
rejected diagnostic runs. The geometry reports run no FDTD. Even an accepted
diagnostic S-parameter report does not close the full row 4.6 SI gate.
`gpu-d0-pml-fixed.json` is the completed, boundary-safe D0 copper-subset run;
`usb-io-pml-fixed.json` is the completed IO USB copper-subset run.
`gpu-d0-boundary-comparison.json` recomputes both D0 spectra with the same
9.8 ns Fourier cutoff on the same board and records the hashes of every raw
port trace used.
