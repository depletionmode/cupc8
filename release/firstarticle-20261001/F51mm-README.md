# Revised first-article manufacturing files

The F51mm archive contains all eight board Gerber/drill, BOM, placement and order file sets, 30 programming assets, ordering/receiving instructions and genuine source-owner evidence. The six row cards are 62 × 51 mm; finger seating and notch remain fixed. Main and System geometry remains unchanged.

The independent archive audit passed every member hash and reconstructed all eight genuine build owners. Source changes are integrated in commit `801dc7e`.

Use the supplied ordering instructions and retain the documented controlled-development conditions. Supplier CAM/placement review and physical receiving measurements remain required; this release does not claim physical qualification. WiFi and eInk need both-side assembly; the other six use top-side assembly.
